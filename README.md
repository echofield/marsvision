# MARS

Creative researcher and instrument designer working across sound, place and signal.

Local build:

    npm test
    npm run build

Only dist/ is deployed to the separate marsvision Cloudflare Pages project.

## Experience principles

- The homepage is the master journey; external destinations appear only after an internal project chapter.
- SOUND, PLACE and SIGNAL are three states of one lightweight visual field, not separate frontend engines.
- Project returns restore the visitor's previous position in the practice.
- Keep the site static and dependency-free unless a real product need justifies more infrastructure.
